What it is

Code-Call Descriptors

A fat MCP server injects its entire tool schema into context on every turn — tens of thousands of tokens for a one-tool job. CDC converts that server into a compact Agent Skill: a short preamble plus a one-line-per-endpoint reference the agent greps only when it needs it. Same capabilities, a fraction of the standing cost.

Before — native MCP

Connect the GitHub MCP server, ask for one star count, and the window is already full of 1,196 tool definitions you'll never call.

Schema in context: ~3,183,737 tokens

After — CDC skill

Install github-cdc. The agent greps CDC.md, runs one short request, and answers. Schemas stay out of the window.

Skill in context: 909 tokens (3,502× smaller)

Always-on router

It decides per server, by cost

Before the first tool call, the router weighs the native schema against the CDC skill and takes the cheaper path at equal accuracy — even when you explicitly ask to “use the MCP.” Small surfaces stay native; large ones convert. You don't choose; it measures.

Large schema
github MCP · 1,196 tools · ~3.18M schema tokens
→ over threshold, routes to the github-cdc skill (909 tokens)
Small schema
a handful of tools · a few hundred schema tokens
→ under threshold, stays native MCP — converting wouldn't pay off
SignalDefaultEffect
Schema tokens≥ 3,500prefer CDC
Tool count≥ 40prefer CDC
MCP ÷ skill ratio≥ 1.8×prefer CDC

Converting a large MCP prints a one-time cost line; every session afterward is cheaper.

Install

Two commands

Requires Node 18+ on your PATH. Restart Claude Code or Codex afterward.

Both agents — recommended

# clone and install skills + hooks
git clone https://github.com/nassimkhatiba-ai/cdc.git
cd cdc
node bin/cdc.js install-plugin

Skills install to ~/.claude/skills and ~/.codex/skills; the router stays on via Claude hooks and ~/.codex/AGENTS.md.

Claude Code only

claude plugin marketplace add nassimkhatiba-ai/cdc
claude plugin install cdc@cdc

Then just ask

› Convert my GitHub MCP into a CDC skill
› Use the github MCP   # still cost-checks first
